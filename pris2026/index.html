Case Assembly

02
Image-role Refinement

แยก รูปคำถาม / รูปคำตอบ / รูปที่มีชื่อยาอยู่แล้ว

พบจริง: package / pill photo บางรูปของคนตอบถูกเปิดเป็นคำถามใหม่
03
Drug-name Extraction

เพิ่มตัวย่อที่เภสัชกรใช้จริง เช่น pred · para · cpm · ibu · พารา

AI เสนอคำย่อ → เภสัชกรยืนยัน → ป้อนกลับเข้า dictionary
04
OCR → Drug Entity

นำข้อความจาก ซอง / ฉลาก / ภาพคำตอบ กลับเข้าสู่ extractor

OCR ไม่ควรจบแค่ “อ่านข้อความได้” แต่ต้องเชื่อมเข้า entity pipeline
05
Image Scoping

ผูก ชื่อยา / entity → image_id ให้รู้ว่าคำตอบนั้นเป็นของภาพใด

จาก “รู้ชื่อยาในเคส” → “รู้ชื่อยาของภาพนี้”

A1
DINOv2 Image Embedding

แปลงภาพเป็น representation แล้วค้นหาภาพอ้างอิงที่ใกล้เคียง

A2
Internal Baseline: Colour Similarity

เทียบกับวิธีง่ายกว่า บนภาพชุดเดียวกัน เพื่อดูว่า embedding เพิ่มประโยชน์จริงหรือไม่

A3
External Benchmark

นำตัวอย่างไปเทียบกับระบบระบุยาภายนอก/ระบบอ้างอิง (เช่น Drugiden2) ภายใต้เกณฑ์ Top-k ที่เปรียบเทียบได้

A4
Top-k + Paired Statistics

วัดอันดับที่พบ Ground Truth และใช้ McNemar / confidence interval สำหรับการเปรียบเทียบแบบคู่

ความหมายของผล: วัดความสามารถในการ “ลดพื้นที่ค้นหา” ไม่ใช่ความแม่นยำทางคลินิกของคำตอบสุดท้าย
